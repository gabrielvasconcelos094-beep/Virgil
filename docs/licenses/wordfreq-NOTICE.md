# Listas de frequência (engine/analysis/src/main/resources/freq)

Derivadas do projeto **wordfreq** 3.1.1 (Robyn Speer e colaboradores, https://github.com/rspeer/wordfreq):
as 50 000 formas mais frequentes de cada idioma (lista "large"), filtradas para palavras alfabéticas,
uma por linha, em ordem de frequência.

- Código do wordfreq: Apache License 2.0.
- Dados de frequência: **Creative Commons Attribution-ShareAlike 4.0** (CC BY-SA 4.0). As listas
  derivadas incluídas no Virgil são distribuídas sob a mesma licença. Fontes originais agregadas pelo
  wordfreq: Wikipedia, OpenSubtitles 2018, SUBTLEX, Google Books Ngrams, NewsCrawl, GlobalVoices,
  Reddit e Twitter, entre outras (detalhes no repositório do wordfreq).
